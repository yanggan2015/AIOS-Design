# AIOS 设计方案

基于 Linux 的 **AI 操作系统（AIOS）** 完整设计文档仓库。

## 核心命题

系统自带 AI 引擎与 Agent；通过操作系统级 **桌面操控平面（DCP）**，使桌面应用在**没有 AI 接口**的情况下也可被 Agent 操控。
